# 🛒 E-Commerce Website

A modern, responsive, and interactive e-commerce website built with HTML, CSS, and JavaScript. This project focuses on delivering an engaging shopping experience through a clean user interface, smooth interactions, and responsive design.

---

## 📖 Overview

This project demonstrates the design and development of a professional online shopping website. It includes attractive layouts, interactive components, and a responsive user interface that works across desktop, tablet, and mobile devices.

---

## ✨ Features

- 🏠 Modern Home Page
- 🛍️ Product Listing
- 🔍 Product Search
- 📂 Category Filtering
- ❤️ Wishlist UI
- 🛒 Shopping Cart
- 📄 Product Details Page
- 📱 Fully Responsive Design
- 🎨 Smooth Animations & Transitions
- 🌙 Modern User Interface
- ⚡ Fast and Clean Layout

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
